Featured projects

Full-stack project

Darzify — Digital Tailor Shop

A bilingual (Urdu / English) point-of-sale web app for a tailor shop: booking, measurements, pricing, advance payment and order-status tracking, built to keep working without internet.

View on GitHub (opens in a new tab)
  • Offline-first: installable PWA with a service worker; orders and customers stored in IndexedDB via Dexie.
  • Thermal receipts: Urdu tickets drawn on a canvas and sent as ESC/POS raster over Web Bluetooth, Web Serial or a Java Android bridge.
  • Secured API: Express API protects settings and order deletion with salted PBKDF2 PIN hashing and expiring session tokens; JSON backup and restore.
  • Verifiable receipts: unique codes and SHA-256 fingerprints for tamper detection; PDF receipts shareable via WhatsApp.

AI Integrity Checker for Research Papers

A web platform where a user uploads a research paper and sees how much of it is human-written and how much is AI-generated. It does the same for pictures (AI-generated vs captured) and presents the result as a report.

  • My contribution included: the Flask backend and REST API, the React front end and a normalized SQLite schema (users, documents, reports).
  • API design: documented endpoints for upload, processing status and report retrieval with consistent JSON and HTTP errors.
  • Safe uploads: type and size checks, safe file naming and structured error messages.
